    PLANT SETUP

    One site. Two map layers.

    Your robot's navigation map describes free space. The openTCS plant model defines the permitted network of points, paths and stations.

    1. 01

      Survey the real workspace

      Build and validate a SLAM map on the robot. Save the image and its map metadata together.

    2. 02

      Align the coordinate systems

      Use the same origin, orientation and measured scale. ROS uses metres; openTCS model coordinates use millimetres.

    3. 03

      Load a measured plant model

      Define stations and approved routes in openTCS Model Editor, load the model into the kernel, then refresh this view.

    This view displays the live plant model. It does not generate or approve routes from an image.
