当前 `app.js`、`fleet-api.js`、`editor.js` 均为 IIFE。以上迁移不要求更换框架，不创建六份重复 HTML，也不要求一次把现有代码全部改成模块。

### 路由与文件目录是两件事

`#/operations` 等仅为拟议客户端路由，尚未存在；它们可以共享 `index.html`，静态 hosting 不必立即增加六个实体页面。对象详情可先由选中项和 inspector 状态表达，待真实需求出现再增加详情路由。

`editor.html` 和 `/twin/` 保持各自真实入口，迁移期间不伪装为已经实现的内部子路由。未来若采用 `/operations` 等干净路径，必须先配置服务端页面 fallback，并严格区分静态页面回退与 `/api/...` 的真实 404/错误响应；不能将 API 失败回退成 HTML。本文不实施路由或服务器变更。

## 4. 拟议物理文件组织

这是按需迁入的目标目录，不是本次新建文件清单。一次只建立当前切片需要的模块，不生成几十个空占位文件。

```text
agvapp/
  index.html                    # 保留统一入口
  editor.html / editor.js / editor.css
                                # 保留现有独立草稿编辑器
  app.js / fleet-api.js          # 过渡期继续使用的 IIFE 入口/适配器
  sw.js / manifest.webmanifest
  src/                          # 后续按切片逐步采用 ES modules
    shell/                      # 全局环境、导航、选择上下文与连接状态
    pages/
      operations/  missions/  maps/  fleet/  simulation/  events/
                                # 逻辑页面控制与组合，不各复制 HTML 壳
    components/
      site-map/                 # 同坐标图层、对象选择与视口
      object-inspector/         # 车/任务/站点/资源详情
      task-form/  readiness/  event-timeline/  env-badge/
    services/
      fleet-api/                # 现有管理命令、模型、车辆与回执适配
      map-workspace-api/        # 草稿与未来独立发布工作流
      simulation-api/           # 场景、worker、run 与结果适配
      event-stream/             # 订阅、重连、游标和持久查询
    domain/                     # 身份、版本、状态、回执、时间/来源合同
    styles/                     # 共享 tokens 与按需页面样式
```

开始时一个逻辑页面或组件可以只有一个模块，不强制每个目录再拆 controller/store/view。`domain` 负责前端状态映射与合同校验，不承接调度、资源仲裁或机器人控制；services 适配实际后端，不虚构当前不存在的 API。

## 6. 地图与任务的实际边界

- 背景图片、导航占据栅格、调度拓扑可有不同数据来源，但必须通过明确变换落在同一场地坐标，并绑定可追溯版本；至少保留单位、frame、origin/yaw、分辨率、配准及模型版本。页面区分草稿、已发布 live 与 replay 快照。
- `publish draft != live`：草稿的保存、校验成功或导出 JSON，都不等于已发布、已分发或车辆可执行。当前编辑器导出的新拓扑不含完整车辆、包络和驱动属性，不能直接作为覆盖运行模型的发布包。
- 当前 job 输入实质为 `{robotId, destination, requestId}`；`requestId` 在管理消息信封中，`create_order` 命令携带车辆与目的站。其执行范围是导航/NOP，当前不支持来源取货点、cart、lot、lift 或完整取放流程，页面不得用“搬运完成”冒充实际只有到站。
- 工位终端标签与呼叫按钮/LED 的关联仅为业务研究方向；设备身份、呼叫幂等/确认、指示灯状态来源、任务绑定、取消与离线行为尚需合同与实测。当前不能把一个按钮/灯原型说成已连通产线搬运。
