# 门户角色

门户按“谁在用、要完成什么”组织，而不是按后端模块组织。

| 角色 | 日常要做的事 | 看到的页面 |
| --- | --- | --- |
| **操作员**（当班） | 看车在哪、在干什么；派车到工位；处理异常（离线、故障、等待、任务失败）；暂停或恢复派发 | 运行总览（地图 + 异常 + 任务队列）、任务、车辆、历史记录 |
| **主管**（生产长） | 看本班任务完成情况和异常原因；回看某段时间发生了什么 | 同操作员；重点用任务和历史记录 |
| **工程师**（调试、维护） | 编辑和发布地图、搭场景、启停仿真、注入故障、查原始订单与请求回执 | 以上全部，加上打开“工程模式”后出现的地图与发布、仿真工作台和各处的“详情” |

## 规则

- 主流程只说当前状态：前往某工位、等待谁让路、已到达、失败及原因。不解释“这不能证明什么”。
- 原始 ID、哈希、JSON、openTCS/VDA 5050 名称只在工程模式或折叠的“详情”里出现。
- 工程模式是页头的开关，默认关闭，按浏览器记住。直接打开工程页面链接时会自动打开工程模式。
- 目前所有人共用一把操作员密钥，门户还没有按账号区分角色。角色的分工靠页面布局和工程模式体现；按账号授权要等网关支持用户与角色后再做。
